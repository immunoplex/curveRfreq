# Summarise Ensemble Fit Statistics

Extracts AIC, BIC, RSS, df, and convergence status for each model.

## Usage

``` r
summarise_ensemble(ensemble)
```

## Arguments

- ensemble:

  Output of
  [`fit_ensemble_nls()`](https://immunoplex.github.io/curveRfreq/reference/fit_ensemble_nls.md).

## Value

Data frame with one row per model.
